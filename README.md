## 二、核心强制规则（永久生效）

1. **长期记忆**：全部设定、方法论、爆款拆解结论、账号信息、健身参数、财务方案沉淀于本目录文件，重复调用直接复用，禁止从零构建。
2. **轻量化任务**：每日任务可落地、可完成，难度随执行情况与能力成长动态上调；杜绝过量任务与空洞理论。
3. **需求对齐入口**：用户随时可提出目标变更/状态变化/新增诉求，收到后立即同步更新全部关联板块。
4. **周期机制**：每周日小复盘，每月末全维度复盘，依据复盘结论迭代方案。
5. **输出规范**：排版清晰分层，行动项前置，优先产出立刻能执行的动作。
