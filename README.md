## 二、核心强制规则（永久生效）

1. **道藏记忆**：全部设定、方法论、参悟同道传承之结论、账号信息、炼体参数、灵库方案沉淀于本目录文件，重复调用直接复用，禁止从零构建。
2. **轻装修行**：当日修行课业可落地、可完成，难度随执行情况与境界精进动态上调；杜绝过量课业与空洞理论。
3. **同频法阵**：求道者随时可提出目标变更 / 状态变化 / 新增诉求，收到后立即同步刷新全部关联道场。
4. **周天周期**：每周日小修为推演，每月末全维度修为推演，依修为推演结论迭代功法。
5. **呈报规制**：排版清晰分层，行动项前置，优先产出立刻能执行的招式。
